# AURA Studio Mockup

Create a complete, highly realistic, and fully functional interactive mockup of a premium streetwear and modern fashion e-commerce website for a fictitious brand named "AURA Studio". The site should look like a premium, production-ready web application with a sleek, minimalist Scandinavian design aesthetic (clean typography, generous whitespace, high-contrast monochrome accents, and smooth micro-interactions).

The application must include the following pages and features, fully navigable via a responsive Navbar and Sidebar (for mobile):

1. Landing Page (Home):

- Hero Section: High-impact typography, a compelling brand tagline ("Elevate Your Daily Ritual"), and a prominent "Shop New Arrivals" Call-to-Action.

- Curated Collections: Visual grid displaying categories like "Minimalist Essentials", "Oversized Outerwear", and "Aesthetic Accessories".

- Trending Products: A carousel or grid showcasing 4 featured products with dynamic hover states.

- Brand Philosophy: A clean layout explaining the brand's fictional commitment to circular design and ethical textiles.

2. Shop / Catalog Page:

- Interactive Filters: Sidebar allowing users to filter mock products by Category, Size (S, M, L, XL), Color, and Price Range.

- Sorting Dropdown: Functional sorting by "Price: Low to High", "Price: High to Low", and "Newest".

- Product Grid: Display at least 8 distinct fictional products (e.g., "Heavyweight Boxy Hoodie", "Raw Denim Cargo Pants", "Unstructured Wool Blazer", "Oversized Waffle Knit Tee"). Each card must feature a mock image placeholder (using high-quality Unsplash fashion photography URLs), title, price, color swatches, and a functional "Add to Cart" button.

3. Product Detail Page (Dynamic Mockup View):

- Clicking any product should open a dedicated product detail view.

- Includes a multi-image gallery placeholder, size selector buttons, a detailed fabric description, and an "Add to Cart" selector.

4. Fully Functional Shopping Cart & Checkout Flow:

- Interactive Slide-out Cart Panel: Shows items added, item counters, price calculations (Subtotal, Estimated Tax, Shipping), and an option to remove items.

- Mock Checkout System: A step-by-step multi-stage checkout wizard (Shipping Address -> Payment Method -> Fictional Order Confirmation Screen with a summary and dynamic tracking number).

5. Extra Sections for Realism:

- About Page: A beautiful storytelling layout tracking the fictional origin of "AURA Studio".

- Interactive Newsletter: A footer subscription form that gives a success toast message upon submission.

- User Dashboard Mockup: A small "My Account" area showing fictional past order history.

Technical & UI Requirements:

- Use Tailwind CSS for a modern, responsive layout.

- Ensure all buttons, links, toggles, and state changes work smoothly (use local state/context for the cart system).

- Include toast notifications (e.g., using Sonner or shadcn toast) when items are added to the cart or when forms are submitted.
